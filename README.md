# 💰 Rastreador de Despesas

Página web para controlar gastos: definir um orçamento, adicionar despesas por categoria e acompanhamento do valor total, média, saldo e por maior categoria. 📊

Projeto do Sprint 7 (JavaScript básico e lógica de programação). O HTML e o CSS já estavam prontos; a lógica em JavaScript fica em `scripts/calculations.js`. 🚀

## ✨ Funcionalidades

- 🎯 Definir orçamento
- ➕ Adicionar e remover despesas
- 📈 Ver estatísticas gerais e por categoria
- 🚦 Saldo com cor de alerta: 🟢 verde, 🟠 laranja (menos de 25% do orçamento) ou 🔴 vermelho (negativo)

## 🛠️ Tecnologias

HTML, CSS e JavaScript
